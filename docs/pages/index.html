design-bridge

The same registry and the same design tokens, rendered by two different frameworks.

Each library below is generated from one registry.json and one set of W3C DTCG tokens. Nothing here is written by hand: a push to main regenerates the stories, rebuilds both Storybooks and republishes this page.

Vue library

Three components, eleven stories, built with the Vue 3 + Vite adapter.

Open the Storybook →

Angular library

The same three components through the Angular builder, standalone components.

Open the Storybook →

Both libraries read the identical token file, so a colour changed once in Figma moves both at the same time — that is the whole point of the bridge. Source, registry schema and the Figma plugin live in the repository.
